# 📊 Data Analyzer and Transformation

## 📌 Project Overview

The **Data Analyzer and Transformation** is a menu-driven Python application designed to perform basic data analysis and transformation operations on 1D and 2D datasets.

This project allows users to input data, view data summaries, calculate factorials, filter and sort data, and display useful dataset statistics.

It demonstrates the use of Python functions, recursion, lambda functions, built-in functions, list operations, and conditional statements.

## ✨ Features

1. **Input Data**
   - Accepts 1D list data.
   - Accepts 2D list (matrix) data.

2. **View Data Summary**
   - Calculates total number of elements.
   - Finds minimum and maximum values.
   - Calculates the sum and average of the dataset.

3. **Calculate Factorial**
   - Calculates the factorial of a number using recursion.

4. **Filter Data**
   - Filters elements greater than or equal to a given threshold.
   - Uses the `filter()` function and lambda expression.

5. **Sort Data**
   - Sorts data using the `sort()` method.
   - Uses the `sorted()` function for descending order.

6. **Dataset Statistics**
   - Displays total elements.
   - Separates even and odd numbers.
   - Finds the highest and lowest numbers.

7. **Function Documentation**
   - Displays documentation (docstrings) of different functions.

8. **Exit**
   - Safely exits the application.
